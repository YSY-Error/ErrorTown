# 错误庄园 · 玩家使用指南

这份指南从玩家角度说明本插件的用法。管理员配置请看
[admin-guide.md](admin-guide.md)。

所有指令都以 `/sh` 开头（等价写法 `/st`）。菜单里点按钮就等于执行对应指令，
所以记不住指令的话，**按住 Shift 再按 F 打开主菜单**就够了（主菜单指令是
`/sh open`，`/sh menu` 是等价写法）。

> **以游戏内实际效果为准**：游戏内 `/sh help` 的部分页面与本文不一致
> （例如 `help` 里出现的 `untrust`、把 `delete` 写成删家园），那些是语言
> 文件的滞后，实际可用指令以本文为准。

## 1. 快速上手

第一次进服后，你只需要做三件事：

```
/sh create        创建一个家园（按服务器默认类型直接创建）
/sh home          回到自己的家园
/sh open          打开主菜单（/sh menu 等价，或按住 Shift+F）
```

创建成功后你会被自动传送进家园。家园是一块只属于你的世界，**名字自动生成**：
第一个叫你的玩家名，第二个叫 `你的名字_2`，以此类推，不需要（也不能）自己起名。
边界从 8×8 起步，升级后扩大，最大 96×96。别人想动你的东西必须先被你加为
成员或管理员。

平时最常用的几个：

| 指令 | 作用 |
| --- | --- |
| `/sh home`（`/sh h`） | 回家 |
| `/sh tpset` | 把回家点设到你站着的位置 |
| `/sh open` | 主菜单 |
| `/sh visit <玩家>` | 参观别人的家园 |
| `/sh homes` | 列出自己拥有的家园 |
| `/sh help` | 分页帮助（1–6 页） |

## 2. 创建家园

`/sh create` 不带参数时按服务器默认类型创建（默认类型由管理员设置）；
`/sh open create` 打开创建菜单选类型。可选类型：

| 类型 | 说明 |
| --- | --- |
| `1` | 普通自然地形（服务器多数默认这种） |
| `2` | 超平坦 |
| `airland` | 空岛（出生在一个小岛上，带一个开局箱子） |
| `random` | 从服务器预设的模板里随机抽一个 |

**家园名与数量**：家园自动编号（见 §1），每人最多拥有几个由服务器决定
（默认 3 个）。第二个家园就是 `你的名字_2`，回家用 `/sh home 2` 或
`/sh home 你的名字_2`。

**费用**：创建收费（服务器管理员可关）。创建菜单里**左键 = 随机种子，
右键 = 指定种子**，两档价格不同（默认 59999 金币 + 520 点券 /
99999 金币 + 999 点券）。金币优先扣，不够才看点券。付费后世界创建失败
会自动退款，不需要找管理员。

**排队**：人多时创建会排队，菜单会显示你的位置，轮到你才真正开始生成。
服务器同时最多在建 1–2 个世界，所以高峰期要等一会。

**其他**：管理员可以开启「创建前清空背包」，创建时按提示为准。

**删除家园**用 `/sh wholedelete`：第一次执行会发一条**可点击的确认消息**，
点它才真的删。删除次数有限制（默认 3 次），删了之后钱不退，想清楚再删。
（`/sh delete` 不是删家园，是把某人移出你的成员列表，见 §4。）

## 3. 回家与传送

| 指令 | 作用 |
| --- | --- |
| `/sh home`（`/sh h`） | 回到自己家园的回家点 |
| `/sh home <序号/庄园名>` | 有多个家园时指定回哪个 |
| `/sh homes` | 列出自己拥有的家园 |
| `/sh tpset` | 把回家点设到当前位置（需是房主或管理员，站在自己家园里） |
| `/sh visit <玩家>` | 到某玩家的家园参观 |
| `/sh tp <玩家>` / `/sh v <玩家>` | 同上，另一种写法 |
| `/sh visit`（不带参数） | 打开参观菜单，按人气+鲜花排名展示 |
| `/sh look` | 查看当前家园的信息（等级、边界、人气等） |
| `/sh check` | 列出自己是成员的家园 |

**参观规则**：对方家园设为公开（`/sh public`）时任何人都能进；非公开时
只有成员和管理员能进。被对方拉黑（deny）的玩家即使家园公开也进不去。
站在边界外会被服务器按配置处理（减速 debuff、弹回，或被设为**冒险模式**
无法破坏方块）——想帮朋友盖房子，让他把你加成成员。

**边界**：家园四周有边界（原版边界墙 + 四角的全息标记）。边界大小 =
等级决定的尺寸 + VIP 加成，具体数字用 `/sh look` 看。

## 4. 成员、管理员与黑名单

家园的成员体系分三级：

- **成员**：可以在家园里建造、拾取（具体开关见 §6 规则）。
- **管理员**：除了成员权限，还能帮你邀请别人、调整部分设置。
- **黑名单（deny）**：禁止进入你的家园，即使家园公开。

| 指令 | 作用 |
| --- | --- |
| `/sh trust <玩家>`（`/sh t`、`/sh add`） | 加为**成员** |
| `/sh invite <玩家>` | 邀请某人为**管理员**（对方收到提示） |
| `/sh accept` | （被邀请方）接受管理员邀请 |
| `/sh remove <玩家>`（`/sh del`、`/sh delete`） | 移出**成员** |
| `/sh kick <玩家>` | **房主专属**：把人踢出家园（管理员也会被一并撤掉） |
| `/sh deny <玩家>` | 拉黑 |
| `/sh undeny <玩家>` | 解除拉黑 |
| `/sh upgrademember` | 成员扩容（付费，见下） |

这些操作也可以在主菜单的「成员管理」页里点按钮完成。

**人数上限**：成员默认 10 人、管理员默认 2 人。上限可以被服务器发的 VIP
权限放大，也可以付费扩容（`/sh upgrademember`，每次扩容**同时**抬高成员和
管理员两个上限，最高到服务器设定的绝对上限）。

被踢出家园时你会被自动送回主世界出生点，背包不受影响。

## 5. 升级家园

`/sh update` 打开升级菜单（或在主菜单点升级按钮）。

升级的效果是**扩大边界**：8×8 起步，每升一级加一圈，最大 96×96（12 级）。
升级方式由服务器决定，可能有金币、点券、物品（比如钻石）三种，菜单里只显示
服务器开启的（默认只开物品升级）。

| 相关指令 | 作用 |
| --- | --- |
| `/sh update` | 打开升级菜单 |
| `/sh look` | 查看自己家园的等级、边界大小、成员数等 |

服务器可能给 VIP 发折扣权限（如 `st1`/`st2`/`st3`），升级时自动按比例减免，
多个折扣取最优惠的一档。

升级不会影响你已经拥有的 VIP 边界加成 —— 加成只多不少。

## 6. 家园设置

在主菜单「家园设置」里可以改这些（对应的指令一并列出）：

| 指令 | 作用 |
| --- | --- |
| `/sh public` | 公开/关闭家园（**开关式**：再执行一次就关回去） |
| `/sh pvp` | 开关家园内 PVP（默认关） |
| `/sh pickup` | 开关成员能否拾取物品 |
| `/sh drop` | 开关成员能否丢弃物品 |
| `/sh rule <规则> <开/关>` | 家园规则：`explosion`（爆炸）、`fire`（火焰蔓延）、`mob`（刷怪）、`grief`（破坏）、`hostile`（敌对生物）、`passive`（动物）、`spawner`（刷怪笼）、`breed`（繁殖）、`mobcap`（刷怪上限，**3 级解锁**） |
| `/sh locktime` | 锁定时间 —— **3 级解锁**，服务器可关 |
| `/sh day` / `/sh night` | 直接设为白天/黑夜（解锁等级同上；用了之后时间锁会解除） |
| `/sh lockweather` | 锁定天气 —— **3 级解锁** |
| `/sh sun` / `/sh rain` | 直接设晴天/雨天（用了之后天气锁会解除） |
| `/sh cicdifficulty` | 切换难度（聊天输入里确认费用）；等价写法 `/sh GAMEMODE EASY/NORMAL/HARD/PEACEFUL` |
| `/sh setBiome <群系>` | 修改家园群系，**3 级解锁**，按区块收费（菜单里选也行） |
| `/sh title <标题>` | 设置家园标题（显示在参观列表） |
| `/sh desc <描述>` | 设置家园描述，最多 5 行 |
| `/sh icon` | 设置家园图标（参观菜单里显示的物品） |
| `/sh info <文本>` | 设置家园的**宣传语/广告**（`/sh look` 时展示；要用彩色代码需额外权限） |
| `/sh fly on` / `/sh fly off` | 房主/管理员给**整个家园**开关飞行（影响里面所有人） |
| `/sh togglecc` | 切换自己的临时边界显示（某些服务器提供） |

**注意**：难度只影响怪物伤害等行为，刷不刷怪由 §6 里的 `mob` 规则决定。
锁时间锁的是你的家园世界，不影响其他世界。

## 7. 家园专属下界与末地

如果你的服务器开启了「家园专属下界」：

| 指令 | 作用 |
| --- | --- |
| `/sh createNether` | 为你的家园创建一块**专属下界**（默认 20000 金币 + 400 点券，一次性的） |
| `/sh resetNether` | 重置专属下界（默认 10000 金币 + 200 点券，地形重新生成） |
| `/sh resetOverworld` | 重置主世界地形（自定义种子需额外付费） |

在家园**主世界**里搭下界传送门并点燃，就能进你的专属下界；在下界里再搭门
传回来。下界的边界和主世界一样大（1:1 坐标对应），是一块独立的刷怪地皮 ——
主世界和下界**各自**算刷怪，等于双倍的怪塔空间。

下界重置后你放在下界里的东西会丢，重置前把值钱的搬回主世界。

**关于末地**：家园专属末地功能已关闭（执行会提示联系管理员）。

**别混淆**：`/sh nether` 和 `/sh end` 是去**服务器公共**的下界/末地世界，
和你的专属下界无关，且默认关闭 —— 提示不可用就是没开。

## 8. 社交：鲜花、人气与礼物

家园有排名系统：参观菜单（`/sh visit`）按「鲜花 × 权重 + 人气 × 权重」
从高到低排序，权重由服务器配置。

| 指令 | 作用 |
| --- | --- |
| `/sh flower` | 给**你当前站着的这个家园**投一朵鲜花（不能投给自己；每天有限制，默认 5 朵，VIP 权限可增加） |
| `/sh flower to <玩家> [数量]` | 远程给某玩家的家园投花（数量 1–64） |
| `/sh look` | 查看当前家园的鲜花数和人气 |
| `/sh gift send <玩家>` | 把**你拿在手里的物品**寄给某玩家的家园（礼物箱最多 45 格） |
| `/sh gift open` | 打开**自己家园**的礼物箱（要站在自己家园里） |

礼物是真实物品，对方在自己家园的礼物箱里取。每人每天能投的鲜花数量由
服务器决定，VIP 权限（`ErrorTown.Flowers.数字`）可以增加。

## 9. 等级解锁的功能

家园等级不只是边界大小，有些功能需要 3 级（默认值，服务器可调）才解锁：

| 功能 | 解锁等级 |
| --- | --- |
| 锁定时间（`/sh locktime`、`day`/`night`） | 3 |
| 锁定天气（`/sh lockweather`、`sun`/`rain`） | 3 |
| 群系修改（`/sh setBiome`） | 3 |
| 高级怪物规则（`/sh rule mobcap`） | 3 |

查看自己家园等级用 `/sh look`。等级不够时执行对应指令会提示你还差几级。

## 10. 常见问题

**Q：创建家园时扣了钱但没传送过去？**
世界生成失败时会自动退款（服务器每 2 分钟重试一次卡住的退款）。如果等了
几分钟还没退款也没家园，找管理员看创建账本。

**Q：怎么让别人进不了我的家园？**
`/sh public` 关公开 + `/sh deny <玩家>` 拉黑。公开家园里不想让某人进来，
deny 他即可；非公开家园本来就进不来。

**Q：我的家园怎么变小了？**
不会变小。边界只会因为升级或 VIP 上线而变大；如果你在边界里看到 VIP 的
全息角标消失了，是他的 VIP 权限随下线暂时收回，边界实际大小不变（重启才
回落），你不会被“埋”在边界外。

**Q：传送回家后脚下悬空/掉虚空怎么办？**
站到方块上再 `/sh tpset` 把回家点改过去。空岛家园自带开局平台和箱子；
实在不行找管理员。

**Q：改了名的玩家怎么找不到家园了？**
家园按玩家名字存储，改名会丢失归属。请恢复旧名字，或联系管理员人工迁移。

**Q：`/sh help` 显示的指令跟本文不一样？**
以本文和服务器实际配置为准 —— 游戏内帮助页有滞后（比如列出了不存在的
`untrust`）。服务器也可以关闭其中任何功能（比如不开启专属下界、不开启
空岛类型），未开启的指令会提示不可用。
